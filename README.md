# Mini-Instagram-style-Backend
i have developed the mini instagram 
we have to run the backend of the project using 
py manage.py runserver

to run the frontend 
>cd frontend
>python -m http.server 3000

it will open in 
http://127.0.0.1:3000/
from here all the things work and the backend server will handle the api and backend logics.

To open admin panel :
http://127.0.0.1:8000/admin
This  Mini Instagram clone built using Django REST Framework (Backend) and Vanilla JavaScript + HTML + CSS (Frontend).
This project implements core social media features such as authentication, posting images via URLs, likes, comments, follow system, profile pages, and search functionality.
